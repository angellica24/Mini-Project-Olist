# Olist E-Commerce Data Analysis

## 1. Project Overview

This project focuses on analyzing the Olist Brazilian e-commerce dataset to understand business performance, sales trends, product category contributions, delivery performance, customer reviews, and payment behavior.

The project applies data analytics techniques to transform raw transactional data into meaningful business insights that can support data-driven decision-making.

## 2. Project Objectives

The main objectives of this project are:

- Analyze sales performance and monthly revenue trends.
- Identify product categories with the highest sales contributions.
- Evaluate delivery performance and identify late deliveries.
- Analyze the relationship between delivery timeliness and customer satisfaction.
- Understand payment methods, transaction values, and installment patterns.
- Develop an interactive business intelligence dashboard.

## 3. Dataset

The project uses the Olist Brazilian E-Commerce Public Dataset, which contains transactional information from an e-commerce platform.

The original dataset consists of multiple tables, including:

- Customers
- Geolocation
- Orders
- Order Items
- Order Payments
- Order Reviews
- Products
- Sellers
- Product Category Translation

## 5. Project Workflow

The project follows these stages:

1. Data Collection – Preparing the original Olist datasets.
2. Data Cleaning – Processing missing values, duplicates, data types, and data quality issues using Python and SQL.
3. Data Validation – Checking data consistency and validating analytical datasets.
4. SQL Analysis – Creating analytical views to support business analysis.
5. Exploratory Data Analysis – Identifying patterns, trends, and business insights.
6. Business Intelligence – Developing an interactive Power BI dashboard.
7. Documentation – Recording the analytical process and findings.

## 6. Analytical Scope

The analysis focuses on three main business areas:

**Sales and Product Performance**

Analyzing monthly sales trends, merchandise sales, average order value, and product category contributions.

**Delivery Performance and Customer Reviews**

Evaluating delivery timeliness, late delivery patterns, and customer review scores.

**Payment Analysis**

Examining payment methods, transaction values, payment records, and credit card installment distributions.

## 7. Expected Outcomes

The final project aims to provide a structured analysis of Olist's e-commerce business performance through SQL analysis, Python-based exploratory data analysis, and an interactive Power BI dashboard.

The results are intended to demonstrate practical data analytics skills, including data preparation, data validation, SQL querying, analytical thinking, and business intelligence visualization.
